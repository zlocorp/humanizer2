# История изменений

## 0.2.0 (2026-11-18)

- Уточнены правила сохранения авторского голоса, аргументации, условий и степени уверенности.
- Улучшены ориентиры для сокращения, заголовков, инструкций, устной речи и материалов с визуалами.
- Добавлены четыре контрольных примера редактуры.
- Список источников и автопроверка расширены до 26 проектов; добавлены проверки состава списка и поля ручного вызова.

## 0.1.0 (2026-11-17)

- Создание, проверка, точечная редактура и переработка текстов на русском и английском.
- Общий навык с автоматическим выбором операции и четыре команды для явного вызова нужного режима.
- Сохранение смысла, фактов, условий, цитат, ссылок и кода. Поддержка авторского голоса по образцам, проверка связности и финальная корректура.
- Плагины для Codex и Claude Code, автономный Agent Skill и установка через ZIP в Claude.ai.
- Проверка новых ревизий 14 изученных проектов с ручным выбором изменений для переноса.
- Лицензия GPL-3.0-only. Лицензия и список источников включены в автономный навык.
