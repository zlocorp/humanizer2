# humanizer2

Редактор русского и английского текста для Codex, Claude Code и других агентов с поддержкой Agent Skills. Помогает написать черновик, проверить текст или убрать лишнее, сохранив смысл, назначение и голос автора.

[Использование](#использование) · [Установка](#установка) · [Примеры](docs/EDITORIAL_EXAMPLES.md) · [Лицензия](#лицензия)

## Использование

Пример команды полного плагина в Codex: `$humanizer2:humanizer2-review`. В Codex префикс `$`, в Claude Code `/`: та же команда выглядит как `/humanizer2:humanizer2-review`. Часть `humanizer2:` — пространство имён плагина; после неё идёт короткое имя режима из таблицы. Добавьте свой запрос и текст или факты.

| Режим | Пример запроса | Что делает |
| --- | --- | --- |
| `humanizer2-review` | «Проверь текст, не переписывай» | Показывает конкретные проблемы и предлагает правки, не меняя файл |
| `humanizer2-edit` | «Убери воду с humanizer2» | Исправляет только нужные места; хороший текст оставляет как есть |
| `humanizer2-rewrite` | «Перепиши для технического блога» | Меняет формулировки и структуру в пределах запроса |
| `humanizer2-write` | «Напиши пост по этим фактам» | Использует задачу, факты и при необходимости образец голоса |

Основной навык полного плагина: `$humanizer2:humanizer2` в Codex или `/humanizer2:humanizer2` в Claude Code. Он выбирает операцию по запросу; автоматический выбор зависит от агента и контекста. Четыре отдельных режима вызываются явно и используют общие правила основного навыка.

При отдельной установке папки `skills/humanizer2` доступен только основной навык: `$humanizer2` в Codex или `/humanizer2` в Claude Code, без пространства имён плагина. Операцию задайте словами.

### Что сохраняется при редактуре

- Факты, числа, условия, отрицания и степень уверенности. Образец голоса не становится источником новых фактов.
- Назначение текста: контакты, обещания, инструкции и призывы к действию, если их изменение не входит в запрос.
- Цитаты, ссылки, код и другие защищенные фрагменты. После сокращений проверяются связность и ссылки между частями текста.
- Авторский стиль, если он задан. Без образца навык ориентируется на жанр и читателя, не придумывает личный опыт или мнение автора.

В конце навык проверяет опечатки, пунктуацию и случайные повторы. Длинный текст обрабатывается по смысловым частям с общей проверкой согласованности. В обычном тексте длинное тире убирается; в точных цитатах и защищенных фрагментах сохраняется.

**Границы:** навык не определяет авторство, не выдает «процент ИИ» и не обещает пройти детектор. Он не заменяет проверку фактов. Получившийся текст стоит перечитать перед публикацией.

## Установка

Выберите один способ: отдельный навык, плагин или ZIP для Claude.ai. Сам навык состоит из инструкций: ему не нужны дополнительные программы или сетевые запросы. Для выполнения нужна модель в выбранном приложении.

### Отдельный навык

Можно поручить установку своему агенту:

> Установи основной навык из https://github.com/zlocorp/humanizer2 для текущего проекта в используемом агенте, без плагина. Скопируй папку skills/humanizer2 целиком, сохрани лицензию и список источников. Если навык уже установлен, не перезаписывай мои изменения без согласования. Проверь, что он обнаруживается, и скажи, как его вызвать.

При ручной установке скопируйте **всю папку [`skills/humanizer2`](skills/humanizer2/)**, включая `LICENSE` и `THIRD_PARTY_NOTICES.md`, в один из каталогов:

| Агент | Только текущий проект | Все проекты на этой машине |
| --- | --- | --- |
| Codex | `.agents/skills/humanizer2/` | `~/.agents/skills/humanizer2/` |
| Claude Code | `.claude/skills/humanizer2/` | `~/.claude/skills/humanizer2/` |

Пути проекта отсчитываются от его корня; `~` означает домашнюю папку пользователя. Обновите список навыков или начните новую сессию. Локальная установка не переносится автоматически на другую машину или в облачную сессию. Подробности: [Codex](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills), [Claude Code](https://code.claude.com/docs/en/skills#choose-where-skills-load).

### Плагин Codex

```sh
codex plugin marketplace add zlocorp/humanizer2
codex plugin add humanizer2@humanizer2
```

Проверьте установку через `codex plugin list --marketplace humanizer2` и начните новую сессию.

<details>
<summary>Обновить плагин Codex</summary>

```sh
codex plugin marketplace upgrade humanizer2
codex plugin add humanizer2@humanizer2
```

После обновления начните новую сессию: уже открытая может использовать прежнюю версию.

</details>

### Плагин Claude Code

```sh
claude plugin marketplace add zlocorp/humanizer2
claude plugin install humanizer2@humanizer2
```

<details>
<summary>Обновить плагин Claude Code</summary>

```sh
claude plugin marketplace update humanizer2
claude plugin update humanizer2@humanizer2
```

В открытом сеансе выполните `/reload-plugins` или начните новый. Автообновление marketplace можно включить через `/plugin` → Marketplaces → humanizer2 → Enable auto-update.

</details>

### Claude.ai

Скачайте репозиторий и создайте ZIP из папки навыка. В терминале macOS/Linux с установленным `zip`, из корня репозитория:

```sh
(cd skills && zip -r -FS humanizer2.zip humanizer2 -x '*/.DS_Store')
```

Можно использовать архиватор: внутри ZIP должна быть папка `humanizer2` с `SKILL.md` и файлом `LICENSE` и списком источников.

В Claude откройте Customize → Skills → «+» → Create skill → Upload a skill и загрузите `skills/humanizer2.zip`. Для работы навыков включите выполнение кода и создание файлов. Для обновления загрузите новый архив.
