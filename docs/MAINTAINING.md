# Сопровождение humanizer2

## Проверка источников

Для проверки новых ревизий нужны Python 3 и доступ к GitHub API:

```sh
python3 scripts/check_upstreams.py
```

Команда сравнивает ревизии с [`scripts/upstreams.json`](../scripts/upstreams.json) и показывает ссылки на изменения. Она не редактирует файлы и возвращает ненулевой код при ошибке проверки.

После ручного разбора обновите проверенные ревизии в `scripts/upstreams.json`, даже если изменений для переноса нет. Список проектов находится в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Проверки

Запустите тесты без сети:

```sh
python3 -m unittest discover -s tests
```

Тесты проверяют скрипт, комплект и структуру навыков, согласованность версий манифестов, наличие иконок и локальных файлов по ссылкам в документации, а также наличие запросов и критериев в примерах. Они не обращаются к модели и не оценивают качество её ответов; [контрольные примеры редактуры](EDITORIAL_EXAMPLES.md) запускаются вручную. Эти же тесты запускаются в GitHub Actions при push и pull request.

Файлы `LICENSE` и `THIRD_PARTY_NOTICES.md` в `skills/humanizer2/` должны совпадать соответственно с `LICENSE` в корне и `docs/THIRD_PARTY_NOTICES.md`. После изменения обновите копии: их наличие и совпадение проверяются тестами.
